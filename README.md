# hyper-fullstack

Kotlin Multiplatform trading app for Android and iOS.

The app shares market behavior in Kotlin and keeps the final UI native:

- `sharedLogic`: KMP market data, networking, parsing, repositories, feature state, and shared resources.
- `androidApp`: Android app and Jetpack Compose UI.
- `iosApp`: iOS app, SwiftUI UI, Tuist project generation, Fastlane signing and upload.

## Architecture

Keep the boundary simple:

```text
Hyperliquid HTTP/WebSocket
  -> shared services
  -> shared repositories
  -> shared feature state
  -> native Android/iOS UI
```

`SharedDependencyGraph` wires the shared Koin graph and exposes the features each platform uses. Android collects shared `StateFlow`s in Compose. iOS observes shared exported features from SwiftUI view models.

Current shared slices cover order book, candles, live prices, market summary, and recent trades. Platform code should focus on rendering, navigation, gestures, haptics, and platform-specific presentation.

## First-Time Setup

Install these first:

- Xcode
- Android Studio or Android SDK command line tools
- Homebrew
- `asdf` with Ruby and Java plugins
- Bundler

The repo pins local tool versions in `.tool-versions`:

```text
ruby 3.4.2
java oracle-17.0.8
```

From the repo root:

```bash
brew bundle
asdf install
bundle install
```

If Homebrew rejects a third-party tap on a new machine:

```bash
brew trust tuist/tuist
brew trust xcodesorg/made
brew bundle
```

Generate the iOS workspace:

```bash
cd iosApp
tuist install
tuist generate --no-open
open iosApp.xcworkspace
```

Use the `iosApp` scheme in Xcode.

## Android

Build from the repo root:

```bash
./gradlew :androidApp:assembleDebug
```

Useful checks:

```bash
./gradlew :androidApp:assembleDebug
./gradlew :sharedLogic:testAndroidHostTest
```

Android Studio should open the repo root. The Android app consumes `:sharedLogic` directly.

## iOS

The iOS project is generated by Tuist from `iosApp/Project.swift`. Do not hand-edit generated `.xcodeproj` files.

Regenerate after changing Tuist config or iOS Swift packages:

```bash
cd iosApp
tuist install
tuist generate --no-open
```

Build an unsigned simulator app:

```bash
xcodebuild \
  -workspace iosApp/iosApp.xcworkspace \
  -scheme iosApp \
  -configuration Debug \
  -sdk iphonesimulator \
  -destination 'generic/platform=iOS Simulator' \
  -derivedDataPath build/xcode-derived \
  CODE_SIGNING_ALLOWED=NO \
  build
```

Or use Fastlane:

```bash
cd iosApp
bundle exec fastlane ios build_simulator
```

During an Xcode build, Tuist runs Gradle scripts that build/embed `SharedLogic.framework` and copy moko-resources into the app bundle.

## Signing and Upload

Signing uses `fastlane match`.

Create local signing config:

```bash
cp iosApp/.env.example iosApp/.env
```

Fill in:

- `FASTLANE_TEAM_ID`
- `MATCH_GIT_URL`
- `MATCH_PASSWORD`
- `APP_STORE_CONNECT_API_KEY_ID`
- `APP_STORE_CONNECT_API_ISSUER_ID`
- `APP_STORE_CONNECT_API_KEY_FILEPATH`

Place the App Store Connect `.p8` key under `iosApp/fastlane/`. Do not commit it.

Sync signing assets:

```bash
cd iosApp
bundle exec fastlane ios sync_development_signing
bundle exec fastlane ios sync_appstore_signing
```

For a new match repository, set `MATCH_READONLY=false` once so match can create certificates and profiles. Set it back to `true` after the first successful sync.

Build and upload TestFlight:

```bash
cd iosApp
bundle exec fastlane ios build_testflight
bundle exec fastlane ios upload_testflight
```

Expected profile names:

- Debug: `match Development org.coreypett.fullstack`
- Release/TestFlight: `match AppStore org.coreypett.fullstack`

## Shared Logic

Important shared packages:

- `di`: Koin graph and platform entry points.
- `network`: Hyperliquid HTTP/WebSocket clients, JSON, serializers, retry behavior.
- `orderbook`: order book DTOs, service, repository, view state, precision/depth helpers.
- `market/candle`: candle history and live chart state.
- `market/price`: live price stream.
- `market/summary`: market metadata and summary state.
- `market/trade`: recent trade stream.
- `moko-resources`: shared colors/images exported to Android and iOS.

Run shared tests:

```bash
./gradlew :sharedLogic:testAndroidHostTest
./gradlew :sharedLogic:iosSimulatorArm64Test
```

## Notes for Peers

- Put durable behavior in `sharedLogic`.
- Keep Android and iOS presentation native.
- Add shared dependencies through `SharedDependencyGraph`.
- Add iOS packages in `iosApp/Tuist/Package.swift` and target dependencies in `iosApp/Project.swift`.
- Add Android/KMP dependency versions in `gradle/libs.versions.toml`.
- Keep `.env`, App Store Connect keys, build products, and local Xcode user state out of Git.
